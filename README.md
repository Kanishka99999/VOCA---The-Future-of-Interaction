# VOCA – Voice-Activated Accessibility Website

![Voca Banner](screenshots/voca-banner.png)

VOCA is a web-based voice-activated accessibility platform designed to help users, especially those with disabilities, navigate and interact with websites using their voice. It integrates speech recognition and text-to-speech features to create a more inclusive digital experience.

---

## Features

- Voice-controlled website navigation
- Text-to-Speech (TTS) support for reading content aloud
- Responsive, accessible design with contrast and readability options
- AI-powered voice interaction support (basic)
- Services section with detailed explanations and images


## Technologies Used

- React.js (Next.js)
- Tailwind CSS
- Web Speech API (for Speech Recognition & TTS)
- HTML5, CSS3, JavaScript
